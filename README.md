### 🚀 Featured Project

#### [server-telemetry-monitor](https://github.com/rhettrostyle/server-telemetry-monitor)
*A lightweight system telemetry and diagnostics dashboard built with FastAPI and psutil.*
- **Cross-Platform Telemetry:** Polls real-time CPU, RAM, and disk utilization across Windows NT and Linux partitions.
- **Root-Cause Diagnostics:** Aggregates, sorts, and inspects top memory-consuming processes alongside CPU utilization for remote site servers.
- **REST API + UI:** Exposes structured JSON metrics endpoints for automated aggregators and an operational web dashboard for field triage.
